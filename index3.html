🔗 엔드포인트 체크 (클라이언트 관점)

브라우저에서 인식한 접속 정보를 표시합니다. 인터페이스 엔드포인트(PrivateLink)의 Private DNS가 활성화돼 있다면 서비스 도메인이 사설 IP로 해석됩니다.

호스트명—
도메인(호스트:포트)—
프로토콜—
현재 시각—
curl -sS -o /dev/null -w "%{http_code}\n" https://example.com/

💡 서버에 /health 엔드포인트가 있다면 / 대신 /health로 변경해 확인하세요.

🔐 HTTPS : 443
🧭 Region-agnostic
🏷️ Private DNS 권장

🧭 안내

  • 이 페이지는 엔드포인트 랩을 위한 간단한 데모용 정적 페이지입니다.
  • Interface Endpoint(PrivateLink)를 사용할 때는 엔드포인트 SG 인바운드로 TCP 443을, 소스는 클라이언트 SG로 제한하는 것이 권장됩니다.
  • Gateway Endpoint(S3/DynamoDB)는 라우팅 기반으로 동작하며 SG가 필요 없습니다.
